# ذِكري – تطبيق أذكار صوتي

تطبيق Android شخصي للتذكير بالأذكار والتسبيح والصلاة على النبي ﷺ باستخدام تسجيلات صوتية يختارها المستخدم.

## المصدر
سيُضاف كود التطبيق وملفات البناء في المجلد `DhikriAndroid/` بعد إتمام رفع المصدر.

## الحالة
هذه صفحة تعريفية أولية؛ لا تعني أن التطبيق بُني أو اختُبر على جهاز Android.
